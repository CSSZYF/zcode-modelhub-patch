model-hub ZCode 模型拉取补丁 (v2.2.0)
=====================================

适配: ZCode Desktop 3.14.3 (Personal Model 设置页重构版)
注意: v1.x 是给 3.13 及更早版本写的, 锚点在 3.14 系已不存在, 3.14.3 必须用本版。

功能
----
给 ZCode 桌面版的「模型供应商」设置注入:
- 添加渠道 / 编辑渠道 页面均有「拉取模型」按钮
- 填好 BaseURL 和 API Key 后一键拉取该端点的全部模型 (自动尝试 /v1 路径)
- 弹出选择面板: 搜索、全选/全不选、逐个勾选
  再次拉取默认勾选该渠道已选过的模型 (首次拉取默认全选), 确认不会改动原有设置
- 「探测视觉」: 对勾选模型发送 1x1 测试图, 实测是否支持图片输入
- 确认后写入模型列表 (最终态语义: 未勾选的移除, 手动添加的保留)
- 「请求头模拟」: Claude / Codex 预设请求头, 勾选即生效, 粘性保存
- 「思考档位表」(个人模型编辑器): 表格勾选推理等级
  (off/on/minimal/low/medium/high/xhigh/max/ultra), 按从低到高生成, 自定义档位保留
- 隐私: 关闭全部自动上报 (源码级, 还原即恢复):
  ARMS RUM / 磁盘用量 / MCP / 事件上报(event/report) / OTEL 链路与指标(阿里云 ARMS) / 崩溃远程上报
- 修复: 自定义 agent 启动命令时的存储初始化失败; computer-use 插件缺失报错
- 可选引擎补丁: 编辑任意历史消息 (不只最后一条)

使用
----
1. 安装 Node.js (https://nodejs.org 任意 LTS 版本)
2. 先在托盘完全退出 ZCode (右键托盘图标 - 退出; 关窗口不够)
3. 双击「一键安装补丁.cmd」, UAC 点「是」
   脚本会: 校验锚点 -> 备份原版 -> 打补丁 -> 回读验证 -> 可选引擎补丁 -> 物化 computer-use 插件
4. 打开 ZCode: 设置 - 模型供应商 - 添加/编辑渠道
   ZCode 自动更新会覆盖补丁, 更新后重新运行一次安装脚本即可

还原
----
双击「还原补丁.cmd」, 恢复官方原版 app.asar 与 zcode.cjs。

要求
----
- Windows + ZCode 桌面版 3.14.0
- 已安装 Node.js

文件说明
--------
- 一键安装补丁.cmd   安装入口 (自动提权)
- 还原补丁.cmd       卸载/还原入口
- patch-core.js      补丁核心 (定位/校验/改写/重打包/回读)
- engine-patch.js    可选引擎补丁 (全消息可编辑)
- snippet-*.{txt,js} 三处注入内容 (纯文本, 便于审阅)
- asar.js            零依赖 asar 解包/打包实现
- VERSION.txt        适配版本与构建时间

安全说明
--------
- 安装前自动备份为 app.asar.modelhub-backup, 还原脚本可完整恢复
- 所有写操作 = 临时文件 + 尺寸校验 + 改名, 失败时原文件不动
- 安装后自动回读验证全部注入点, 任一失败即放弃
- 仅改动 app.asar 内四个文件与 (可选) zcode.cjs, 原生模块零改动
- 探测视觉会向对应 API 发送少量测试请求 (每模型 1 次, 16 tokens)
