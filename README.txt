model-hub ZCode 模型拉取补丁
============================

功能
----
给 ZCode 桌面版的「模型供应商」设置注入「拉取模型」能力：
- 添加渠道 / 编辑渠道 页面均有「拉取模型」按钮
- 填好 BaseURL 和 API Key 后一键拉取该端点的全部模型（自动尝试 /v1 路径）
- 弹出选择面板：搜索、全选/全不选、逐个勾选
- 「探测视觉」：对勾选模型逐个发送 1x1 测试图，实测是否支持图片输入（并发 4）
- 确认后写入模型列表；视觉开关=勾选面板里每行右侧的 文本/视觉 切换

使用
----
1. 右键「一键安装补丁.cmd」→ 以管理员身份运行（会弹 UAC，点是）
   （直接双击也会自动请求提权）
2. 脚本会自动：关闭 ZCode → 备份原版 app.asar → 打补丁 → 完成
3. 打开 ZCode 验证；ZCode 自动更新后补丁会被覆盖，重新运行一次安装脚本即可

还原
----
右键「还原补丁.cmd」以管理员身份运行，恢复官方原版。

要求
----
- Windows + ZCode 桌面版（安装于 C:\Program Files\ZCode）
- 已安装 Node.js（https://nodejs.org 任意 LTS 版本）
- 适配的 ZCode 版本见 VERSION.txt；ZCode 大版本更新后若锚点不匹配，
  脚本会明确报错并自动放弃修改，不会损坏原文件

文件说明
----
- 一键安装补丁.cmd   安装入口（自动提权）
- 还原补丁.cmd       卸载/还原入口
- patch-core.js      补丁核心（提取、改写、重打包）
- asar.js            零依赖 asar 解包/打包实现
- VERSION.txt        适配的 ZCode 版本与构建时间

安全说明
--------
- 安装前自动备份为 app.asar.modelhub-backup，还原脚本可完整恢复
- 所有改动仅限 out/preload、out/main、out/renderer 三个文件内的
  追加/锚点替换，不触碰其他文件
- 探测视觉会向对应 API 发送少量测试请求（每模型 1 次，16 tokens）
